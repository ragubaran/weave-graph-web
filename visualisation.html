Stage 1: Tree-sitter AST Parsing

Raw source files (Rust, Python, TypeScript) are parsed deterministically across CPU cores. Language parsers extract definitions, trait implementations, and function call sites without executing any code or contacting external networks.

The Six Core Architectural Features

1

Tree-sitter AST Syntax Parsing

Traditional regex grep indexers miss macro expansions, trait implementations, and language syntax boundaries.

Weave Graph Invariant: Native Tree-sitter C/Rust bindings parse millions of lines of code into precise syntax trees with microsecond execution times and zero AST leaks across Rayon thread workers.

2

CSR Matrix & Roaring Bitmasks

Standard graph databases represent nodes as heap-allocated structs with pointer vectors, blowing RAM into several gigabytes on large repositories.

Weave Graph Invariant: All symbol strings and file paths are interned into contiguous uint32 Compressed Sparse Row arrays. Peak RSS stays under 80MB RAM for 500,000 symbols.

3

Bidirectional Edge Purging & Atomic Swaps

Incremental reindexing often purges only outbound edges (source_id), leaving dangling incoming edges that corrupt caller traversals.

Weave Graph Invariant: Every incremental update purges both source_id AND target_id, maintaining complete graph integrity. Large rebuilds swap databases atomically via rename(2).

4

Targeted Subgraph Slicing (MCP)

Concatenating raw codebases into prompt dumps (Repomix/Gitingest) consumes 50k–100k tokens and causes severe LLM attention degradation.

Weave Graph Invariant: Exposes exact 2-hop caller/callee subgraphs via native MCP for Claude Code and Cursor. Agents receive 800 dense tokens instead of 30,000 raw tokens — cutting costs by 92% and eliminating hallucinations.

5

Local SLM Intent Routing (weave ask)

Cloud LLMs introduce latency, telemetry risks, and high token billing when developers ask quick structural questions in the terminal.

Weave Graph Invariant: Optional on-device SLM linking (0.5B–3B GGUF models) executes purely in terminal memory. The SLM translates intents into exact MCP tool calls with strict AST parameter grounding and 0MB idle RAM.

6

Multi-Repo Federation & Cycle Detection

Microservices and multi-repository monorepos have opaque cross-boundary call edges, making API changes prone to silent breaking bugs.

Weave Graph Invariant: Link sibling workspaces with weave repo add. Virtual schemas resolve cross-repo calls while Tarjan Strongly Connected Components (SCC) algorithms detect circular dependencies between services.
