# weave-graph-web

The official web platform and product showcase for [`weave-graph`](https://github.com/ragubaran/weave-graph) — the ultra-lightweight, memory-safe code intelligence and knowledge-federation engine built in pure Rust.

## Features
- **Modern Landing Experience**: Hero, terminal playground, architectural pillars, and verified hardware benchmarks.
- **Getting Started & Install**: Channel selector for Homebrew, Cargo, npx, PyPI, and source builds, plus single/multiple mode guides.
- **Market Comparison**: Technical comparison against Sourcegraph, CodeGraph, Graphify, Repomix, and ctags.
- **Release Notes**: v1.0.0 milestone log and release highlights.
- **Interactive Roadmap**: 2026–2027 Phase progression (Core, Team, Custom).
- **Netlify Ready**: Zero-build static runtime configured via `netlify.toml`.

## Local Development
```bash
# Run local dev server at http://localhost:3000
npm run dev
```

## Deployment
Configured for continuous deployment on [Netlify](https://www.netlify.com). Simply link this repository and Netlify will deploy root files with automated cache and security headers.
