How Weave Graph Compares

Weave Graph is a local code graph for AI coding agents: one binary, one SQLite file per repo, queried in-process. Other tools make different trade-offs, and some of them do things Weave Graph does not.

How to read this table: Weave Graph numbers come from the product's own benchmarks (criterion benches and scripts/verify_envelope.sh, one machine; see Performance). CodeGraph cells are vendor-reported, taken from its README and benchmark docs (retrieved 2026-09-12) and not reproduced by us. The other columns describe the general approach of each tool. We have not benchmarked them, so they contain no numbers.

When to Pick What

Vs. Repomix / File Concatenation

Packing a whole repo into the context window is simple and works well when the repo is small. On larger repos it costs tokens, and the model gets a lot of text that has nothing to do with the task.

Weave Graph: The agent asks for a symbol and gets back only that symbol's neighbourhood: its callers, callees and impact radius. Results are capped by a token budget.

Vs. Sourcegraph & SCIP

Sourcegraph is built for code search and navigation across an organisation, with a web UI and precise SCIP indexes. Running it means running a server deployment.

Weave Graph: A single binary that keeps its graph under .weave/ in each repo, with no server to run. The core-only build is 9.67 MiB; the default build is 41.16 MiB.

Vs. Neo4j & Graph Databases

A graph database gives you a general query language over any schema. For code indexing, you also run the database, write a loader, and send every query over the network.

Weave Graph: Traversal runs in-process over compact CSR arrays. A 3-hop traversal takes about 30 µs on the benchmark machine. The query language is small and fixed: callers, callees, impact, path and latency.

Vs. Universal Ctags

Ctags is tiny, fast and supported everywhere. It records where symbols are defined, but it has no caller/callee graph.

Weave Graph: Parses with Tree-sitter and builds directed call graphs, which may contain cycles; weave policy drift reports them via strongly-connected-component detection. On top of that graph it computes blast radius and shortest paths.

Vs. CodeGraph

CodeGraph is the closest tool in this category: a Rust-kernel, SQLite-backed, MCP-served local code graph. According to its own docs, it supports route edges for 17 web frameworks, an interactive viewer, and anonymous telemetry that is on by default.

Weave Graph: No second runtime. The default build contains no network code, and agents get tiered, token-budgeted tools instead of one dense payload. Weave Graph has no framework-route awareness.

Vs. In-Memory Python Graphs (e.g. Graphify)

Python tools are easy to extend and can expose the graph over MCP. They usually hold the whole graph in Python objects and save it as one file.

Weave Graph: Stores the graph in SQLite and loads it into compact arrays: 24 MiB for storage + graph at 500k symbols. A full index run peaks at 244 MiB. It removes edges in both directions on incremental saves, and it can link two repos for cross-repo queries.
