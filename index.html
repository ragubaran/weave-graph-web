          The 3-Tier Intelligence Model
          
Deterministic Core ↔ Local SLM ↔ Frontier LLM

          

            A unified code intelligence architecture connecting microsecond deterministic graph walks with on-device SLMs and frontier coding agents.
          

        


        

          

            

              Tier 1: Foundation
              < 2ms Latency
            

            
Zero-LLM Core Engine

            

              Microsecond Tree-sitter parsers, SQLite WAL storage, and contiguous uint32 CSR adjacency matrices. 100% offline, zero network dependencies, and <80MB RAM for 500k symbols.
            

            
weave index • weave callers • weave check

          


          

            

              Tier 2: Edge SLM
              0.5B–3B GGUF
            

            
Local Intent Router (weave ask)

            

              Natural language terminal routing with zero cloud data egress. Strictly grounds extracted parameters against AST symbols, mining ADR rules and synthesizing Git changelogs with 0MB idle RAM.
            

            
weave ask • weave slm pull • weave journal

          


          

            

              Tier 3: Frontier LLM
              Native MCP
            

            
Autonomous Agent Linking

            

              Direct Stdio & SSE MCP integration for Claude Code, Cursor, Windsurf, and Antigravity. Prunes massive 100k-token file trees into exact 1k-token subgraphs, cutting LLM context bills by 92%.
            

            
weave serve --mcp • Claude • Cursor

          

        

      

    


    
    

      

        

          Engineering Principles
          
Engineered for Hard Invariants

          

            Designed from scratch in Rust 2024 with zero cloud dependencies, bounded memory footprints, and 100% deterministic reproducibility.
          

        


        

          

            
🔒

            
100% Zero-LLM Core

            

              Graph generation, parsing, persistence, and queries execute deterministically via Tree-sitter. No API keys required, zero telemetry, and zero network calls in the base tier.
            

          


          

            
⚡

            
CSR Matrix & Bitmasks

            

              Adjacency lists use contiguous uint32 Compressed Sparse Row (CSR) layouts with Roaring bitmasks. Peak memory never exceeds 80MB RAM for 500,000 code symbols.
            

          


          

            
🛡️

            
Atomic Crash Safety

            

              Never corrupts your database on crash. Index rebuilds write to .weave/graph.db.rebuild and perform atomic swaps. Incremental updates enforce bidirectional edge purges.
            

          


          

            
🤖

            
Native MCP Server

            

              Implements standard Model Context Protocol (Stdio & Localhost SSE) with 92% token reduction. Slices precise 2-hop sub-graphs (800 tokens vs 35,000 raw file dumps) for Claude Code, Cursor, and Windsurf.
            

          


          

            
🌐

            
Multi-Repo Federation

            

              Index multi-repo federations or monorepos with cross-repository call tracing, shared virtual schema layers, and workspace boundaries.
            

          


          

            
🏢

            
Self-Hosted Version

            

              Full enterprise autonomy for air-gapped VPC clusters: query-layer RBAC, SCIM 2.0 directory sync, centralized snapshot registry (weave-registry), and 100% offline execution.
            

          


          

            
📑

            
29+ Language Grammars

            

              Native AST extraction for Rust, Python, TS, Go, Java, C/C++, ArkTS, Solidity, CUDA, Metal, Svelte, Vue, Astro, Terraform, Nix, COBOL, Erlang, and more.
            

          


          

            
🛡️

            
Boundary Contract Verifier

            

              weave check-contracts computes SHA-256 hashes of public interfaces to stop breaking changes and signature drift in CI pipelines.
            

          


          

            
🎯

            
PR Blast Radius (weave blast)

            

              3-dot merge-base git diff analysis graphing transitive callers across pull requests, generating ready-to-post markdown reports for CI.
            

          


          

            
⚖️

            
MIT License
