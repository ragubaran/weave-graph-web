          Core Engine + MCP
          
A deterministic graph, served over MCP

          

            The graph engine parses and stores your repository locally, and coding agents query it over MCP. An experimental local-SLM router is also available.
          

        


        

          

            

              Core Engine
              ~30 µs traversal
            

            
Zero-LLM Core Engine

            

              Tree-sitter parsers, SQLite WAL storage, and a compact uint32 CSR adjacency matrix. Runs fully offline with no network calls in the default build.
            

            
weave index • weave query • weave verify

          


          

            

              Experimental
              0.5B–3B GGUF
            

            
Local Intent Router (weave ask)

            

              A local SLM that routes natural-language terminal queries to graph queries, with no cloud data egress. Not part of the core value proposition — still experimental.
            

            
weave ask • weave slm pull • weave journal

          


          

            

              MCP
              12 tools
            

            
Agent Integration

            

              Stdio or loopback HTTP MCP server for Claude Code, Cursor, and other MCP clients. Agents get the sub-graph around a symbol instead of pasting whole files.
            

            
weave serve --mcp • Claude • Cursor

          

        

      

    


    
    

      

        

          Engineering Principles
          
What agents get, and how

          

            Built from scratch in Rust with no cloud dependencies, a bounded memory footprint, and deterministic queries — the same input always produces the same graph.
          

        


        
For agents

        

          

            
🤖

            
MCP Server (12 tools)

            

              Model Context Protocol over stdio or loopback HTTP for Claude Code, Cursor, and other MCP clients: repo map, file API, call trace, impact radius, and more — 7 core tools plus 5 feature-gated ones.
            

          


          

            
🧭

            
Pre-flight Verification (weave verify)

            

              Checks a file or range for phantom symbols before an agent's edit is applied, catching hallucinated references early.
            

          


          

            
📝

            
Notes & Search

            

              Pin durable notes to symbols (weave note pin, feature: notes) and run full-text search over names, signatures, bodies, and doc comments (weave search, feature: fts).
            

          

        


        
For PR & CI safety

        

          

            
🎯

            
PR Blast Radius (weave blast)

            

              Three-dot merge-base git diff analysis of transitive callers touched by a PR, written as a ready-to-post Markdown or JSON report.
            

          


          

            
🛡️

            
Boundary Contract Verifier

            

              weave check-contracts hashes public interfaces to catch breaking changes and signature drift across linked repos in CI (feature: federation).
            

          


          

            
🪝

            
Pre-push Hook (weave hooks)

            

              weave hooks install writes a local, offline pre-push hook that runs an advisory blast-radius check and a contract check before every push.
            

          

        


        
For multi-repo codebases

        

          

            
🌐

            
Multi-Repo Federation

            

              Link two repositories (weave link) and query, report, or plan a migration across the boundary (feature: federation).
            

          


          

            
📑

            
29 Language Grammars

            

              8 core languages (Rust, Python, JavaScript, TypeScript, Go, Java, C, C++) plus 21 more via lang-extended (on by default), with further languages handled by best-effort surrogate grammars.
            

          


          

            
⚡

            
CSR Adjacency Matrix

            

              A compact uint32 Compressed Sparse Row layout backs the in-memory graph. Storage and graph memory alone stay at 24 MiB at 500k symbols; a full weave index run currently peaks at 244 MiB, above the 80 MiB target — see Performance.
            

          

        


        
For governance

        

          

            
🏢

            
Self-Hosted Version

            

              Query-layer RBAC with path scoping, SCIM 2.0 provisioning, and a centralized snapshot registry (weave-registry) for air-gapped or VPC deployments.
            

          


          

            
📋

            
Policy Lint

            

              weave policy lint enforces declarative architectural boundary rules from .weave/policy.yaml in CI (feature: policy-lint).
            

          


          

            
🛠️

            
Zero-LLM Core

            

              Graph generation, parsing, persistence, and queries all run deterministically through Tree-sitter. No API keys, no telemetry, and no network calls in the default build.
            

          

        


        
        

          

            

              Self-Hosted Tier
              Custom Build
            

            

              Deploying in a VPC, monorepo, or air-gapped cluster?
            

            

              Build with --features custom for query-layer RBAC, SCIM 2.0 provisioning compatible with Okta, Azure AD, and other standard identity providers, a centralized snapshot registry (weave-registry), JSON trace import, and CI policy enforcement.
