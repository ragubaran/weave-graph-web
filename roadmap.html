Development Roadmap

Continuous Evolution

Explore the phased architecture of Weave Graph — from foundational single-repo deterministic speed to multi-repo federation, team collaboration, and local model routing.

Phase 1 • Core Engine Completed & Production Ready

Deterministic Engine & Single-Repo MCP

Ultra-lightweight core (<15MB static binary, <80MB RAM), memory compaction via CSR matrix, and Model Context Protocol (MCP) server for local coding agents.

  • Zero-LLM AST Parsing: Tree-sitter parsers for Rust, Python, and TypeScript/JavaScript.
  • CSR Matrix Layout: Contiguous uint32 adjacency matrices with Roaring bitmasks.
  • Crash-Resilient Indexing: Atomic .rebuild swap and mandatory bidirectional edge purging.
  • Native MCP Server: Stdio and localhost loopback SSE tools for Claude Code, Cursor, Windsurf.
  • Universal Distribution: Automated release pipelines for Homebrew, Crates.io, npm/npx, and PyPI.
Phase 2 • Federation & Team Intelligence Finalizing & In Active Testing

Multi-Repo Federation & Intent Routing

Extending single-repo indexing to cross-repo workspace federations, topological cycle detection, real-time filesystem watchers, and intent-routed SLM integrations.

  • Federation Virtual Schema: Multi-repo linking via weave repo add and cross-boundary call resolution.
  • Topological Analysis: Tarjan's Strongly Connected Components (SCC) for circular dependency detection.
  • Live Delta Watchers: Real-time background AST reindexing via notify-rs.
  • SLM Intent Routing: IntentRouter trait for fast heuristic query routing and zero-cloud triage.
  • Git Blame Provenance: AST node annotation with commit author, churn risk, and recency scores.
Phase 3 • Enterprise Scale & Extensions In Design & RFC

Distributed Replication, RBAC & Local GGUF

Optional features isolated behind Cargo feature flags ensuring zero degradation to default-build latency or RSS.

  • LibSQL / Turso Edge Replication: Read-only replica synchronization across distributed developer pods (feature: turso).
  • Query-Layer RBAC: Security masking implemented inside the storage and traversal boundary, never export-only.
  • Local GGUF / Llama.cpp Engine: Embedded execution of compact 1B-3B quantized models for offline natural language summaries.
  • Architectural Policy Linter: Automated CI verification against layer violations and prohibited call patterns (weave lint).
  • Hybrid Semantic Index: Blending deterministic CSR graph walks with local compact vector reranking.

The Invariant Guarantee

Per Rule §1.8 of our engineering invariants, enabling any optional feature (federation, hub, provenance, slm, rbac, turso) will never measurably degrade default-build query latency or idle RSS.
