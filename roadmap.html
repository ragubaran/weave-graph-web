Development Roadmap

Continuous Evolution

Explore the phased architecture of Weave Graph — from foundational single-repo deterministic speed to multi-repo federation, team collaboration, and local model routing.

Phase 1 • Core Engine Foundation (M1.0–M1.9) Completed & Shipped (v1.0.0)

Deterministic Core, SQLite & Local MCP Server

Ultra-lightweight deterministic engine (<15MB static core binary, <80MB RAM for 500k symbols), integer-compacted CSR graph model, SQLite persistence, and native MCP server for AI coding agents.

  • Zero-LLM AST Parsing (29 Languages): High-throughput Tree-sitter parsers for Rust, TS/JS, Python, Go, Java, C/C++, C#, Kotlin, Swift, and more with relative SCIP monikers.
  • Integer-Compacted CSR Matrix: Contiguous uint32 adjacency matrices (petgraph::csr) with Roaring bitmap set-intersections for sub-millisecond traversals.
  • Crash-Resilient Indexing & Purge: Atomic .rebuild swap and mandatory bidirectional edge purging preventing dangling pointers.
  • Zero-Config AI Agent MCP Integration: Stdio and loopback HTTP MCP server (weave serve --mcp) with auto-registration in .mcp.json and live reload.
  • Smart Ignore Management: Automatic .gitignore and .ignore handling that excludes runtime databases while keeping .weave/config.toml trackable.
  • PR Blast Radius Analysis: Git three-dot diff traversal (weave blast) with markdown and JSON export formats.
  • Strict Quality Standards: ≥90% line coverage enforced across all crates, Google Rust style, and forward N+1 beta compatibility.
Phase 2 • Federation & Team Intelligence (M2.0–M2.8) Completed & Shipped (v1.0.1)

Multi-Repo Federation, Contract Drift & Developer Ergonomics

Cross-repository graph composition, cryptographic boundary contracts, markdown/Obsidian knowledge graphs, debounced watch mode, and local NL intent routing.

  • Federation Virtual Schema (feature: federation): Multi-repo linking (weave link), cross-boundary queries (weave query-federated), and unified canvas maps.
  • Topological Cycle Analysis & Contracts: Tarjan's Strongly Connected Components (SCC) and automated public API contract drift CI gates (weave check-contracts).
  • Markdown & Obsidian Ingestion (feature: docs): Zero-regex streaming markdown parser (pulldown-cmark), wikilinks, and .canvas export.
  • Pinned Symbol Notes (feature: notes): Persistent agent/human knowledge pins (weave note pin/list, MCP recall) with content-hash staleness tracking.
  • Debounced Watch Mode & HTML Viewer: File watcher (feature: watch) with blast-radius gating and offline zero-dependency HTML viewer (feature: viz).
  • Snapshot Hub Client (feature: hub): Network-efficient snapshot hydration and delta publishing (weave sync pull/push).
  • Local SLM Query Intent Router (feature: slm): Deterministic and on-device GGUF intent routing (weave ask, weave journal) with 0MB idle RAM.
  • Pluggable Storage & Python Bindings: Embedded libSQL/Turso replica backend (feature: turso) and standalone PyO3 in-memory query wheels (feature: python).
Phase 3 • Enterprise Scale & Custom Extensions (M3.0–M3.10) In Active Delivery

Query-Layer RBAC, Hybrid Vector Search, SCIM & Registry

Enterprise security controls, distributed trace overlays, architectural boundary enforcement, cryptographic provenance, and two-tier vector search isolated behind zero-overhead feature flags.

  • Query-Layer RBAC (feature: rbac): Storage/traversal boundary node masking with identity enforcement (--as, --require-as) and SCIM 2.0 directory synchronization.
  • Architectural Policy Linter (feature: policy-lint): YAML boundary rule verification (weave policy lint) and architectural drift analytics (weave policy drift).
  • Two-Tier Hybrid Search: High-performance FTS5 BM25 keyword search (feature: fts) and local quantized vector ANN retrieval (feature: vector, sqlite-vec).
  • OpenTelemetry Trace Overlays (feature: otel): Ingesting distributed trace spans (weave traces import) to overlay live p50/p95/p99 latency percentiles on graph nodes.
  • Merkle Snapshot Provenance (feature: hub-provenance): Cryptographic snapshot signing and Ed25519 signature verification before registry ingestion.
  • In-Browser WASM Graph Runtime: Standalone 155.6 KB browser WASM binary (weave-graph-wasm) for client-side offline graph traversal.
  • Central Enterprise Registry Service: Chunked upload spooling and token-authenticated registry backend (weave-registry).
  • Extended Architecture & Drift Waivers: Role-gated drift waivers (--allow-drift) and audited PR blast exemptions (--skip --reason).

The Invariant Guarantee

Per Rule §1.8 of our engineering invariants, enabling any optional feature (federation, hub, provenance, slm, rbac, turso) will never measurably degrade default-build query latency or idle RSS.
