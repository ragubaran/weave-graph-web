Getting Started

Install the weave binary, index your repository, link Local SLM models, and attach AI coding agents via MCP.

1

Install the CLI Binary

Select your package manager. All prebuilt binaries are statically linked with bundled SQLite and zero external runtime dependencies.

⚠ v0.1.0 hasn't tagged its first release yet — Homebrew, crates.io, npm, and PyPI packages aren't published. Build from source below until they land. 

# Clone repository
git clone https://github.com/ragubaran/weave-graph.git
cd weave-graph

# Build optimized production release
cargo build --release -p weave-graph-cli --features slm
cp target/release/weave /usr/local/bin/
# Tap and install the official formula
brew tap ragubaran/tap
brew install weave-graph

# Verify installation
weave --version
# Compile from crates.io with locked dependencies
cargo install weave-graph-cli --locked

# Or compile with optional local SLM support enabled
cargo install weave-graph-cli --features slm --locked

# Verify installation
weave --version
# Run without global install
npx @weave-graph/cli init

# Or install globally
npm install -g @weave-graph/cli
weave --version
# Install via uv (recommended)
uv tool install weave-graph

# Or standard pip
pip install weave-graph
weave --version
2

Initialize and Index Repository

Weave Graph supports both single repository mode and multi-repo / monorepo federations. 

# 1. Initialize inside project root (creates .weave/config.toml)
weave init --mode single

# 2. Build full AST index (parallel Tree-sitter parse across CPU cores)
weave index

# 3. Verify SQLite graph integrity and stats
weave check
# 1. Initialize multi-repo federation
weave init --mode multiple

# 2. Add sibling workspace repositories
weave repo add core ../backend-core
weave repo add api ../gateway-api

# 3. Index all repositories in parallel with cross-repo edge resolution
weave index --parallel

Connect AI Agents (Claude Code, Cursor, Windsurf)

Weave Graph embeds a native Model Context Protocol (MCP) server that runs over standard I/O (stdio) or localhost HTTP/SSE. It cuts agent context consumption by 92% by feeding exact sub-graphs instead of raw source code dumps. 

# Run one command to register Weave Graph in Claude Code:
claude mcp add weave-graph weave serve --mcp

# Verify registration
claude mcp list
// Add to ~/.cursor/mcp.json or workspace .cursor/mcp.json:
{
  "mcpServers": {
    "weave-graph": {
      "command": "weave",
      "args": ["serve", "--mcp"]
    }
  }
}
// Add to ~/.codeium/windsurf/mcp_config.json:
{
  "mcpServers": {
    "weave-graph": {
      "command": "weave",
      "args": ["serve", "--mcp"]
    }
  }
}
4

Local SLM Linking (weave slm & weave ask)

When compiled with --features slm, Weave Graph links a local Small Language Model (0.5B–3B GGUF) for on-device natural language routing with zero cloud data egress and 0MB idle RAM until invoked. 

# Ask questions in natural language right in your shell
weave ask "Who calls verifyJWTSession and what is its blast radius?"

# The SLM strictly grounds parameters against the symbol index:
# Resolved query: get_symbol_callers(symbol="verifyJWTSession", depth=2)
# Traversal execution: 1.4ms via CSR bitmasks (zero hallucinations!)
# Download & checksum-verify a compact GGUF model into cache
weave slm pull qwen2.5-coder-0.5b --sha256 7a1d...

# List available & downloaded models in local registry
weave slm list

# Run the held-out routing benchmark (asserts tool accuracy & TTFT)
weave slm doctor
# Add to .weave/config.toml
[slm]
model = "qwen2.5-coder-0.5b"
backend = "llama-cli"         # or "heuristic" for instant fallback
lazy_load = true             # Guaranteed 0MB idle RSS until weave ask is run
# Mine architectural rules from Markdown ADRs ("services must not call DB")
weave slm review-rules --path docs/adr/

# Confirm candidate rule #1 to enforce in CI via policy-lint
weave slm review-rules --confirm 1

# Synthesize Git diff + graph delta into a structured changelog
weave journal --since HEAD~1

Why 3 Tiers? (Core ↔ SLM ↔ Frontier LLM)

Tier 1 (Deterministic Core) guarantees sub-millisecond CSR graph queries. Tier 2 (Local SLM) acts as a zero-cost on-device translation bridge for terminal developers. Tier 3 (Frontier LLMs like Claude or Cursor) receives exact sub-graph slices via MCP, eliminating hallucinations while saving 92% on token bills.

5

Query Commands Cheat Sheet

You can run graph queries directly from your shell or let agent tools invoke them automatically:

weave callers <symbol>

Discovers every inbound call site referencing a given function, method, or struct across all indexed crates.

weave callees <symbol>

Extracts all downstream symbols and dependencies invoked inside a target definition.

weave impact <path>

Calculates blast radius for refactors: transitive dependents, consumer files, and affected crate boundaries.

weave path <from> <to>

Finds the shortest directed call or dependency path connecting two symbols in the CSR graph.
