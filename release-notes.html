What's New in v0.1.0

1. Zero-LLM Deterministic Graph Core

Graph construction, symbol extraction, and queries execute without contacting external neural APIs. Syntax parsing is handled through native Tree-sitter C/Rust bindings across Rust, Python, and TypeScript/JavaScript.

2. Integer-Compacted CSR Adjacency List

Replaces heavyweight node/edge pointer structs with a contiguous 32-bit Compressed Sparse Row (CSR) matrix backed by Roaring bitmasks. Traversal hops across millions of edges execute in single-digit milliseconds with bounded RSS.

3. Atomic Swap Reindexing & Bidirectional Edge Purge

Crash resilient by design. Large rebuilds write safely to .weave/graph.db.rebuild and execute an atomic OS swap. Incremental updates enforce bidirectional purging of both source_id and target_id, eliminating orphaned graph pointers.

4. Native Model Context Protocol (MCP) Server

Exposes MCP tools (weave_trace_calls, weave_impact_radius, weave_repo_map, weave_file_api) over stdio and localhost loopback. Zero external proxy or adapter required.

5. Multi-Repo & Monorepo Federation Mode

Allows multi-repo federations to be declared via weave repo add, enabling queries to resolve dependencies across workspace boundaries with virtual schemas.

6. Automated GitHub Release Pipeline

Tag push triggers a quality-gated GitHub Actions pipeline (fmt, clippy, full test suite, ≥90% coverage) that builds checksummed binaries for macOS, Linux, and Windows and publishes them as a GitHub Release. Homebrew, Cargo, npm, and PyPI packaging is planned but not yet automated — see Getting Started for what's installable today.

7. Local SLM Linking & Intent Routing (--features slm)

Optional on-device SLM linking (weave ask) for zero-cloud terminal queries. Strictly grounds natural language inputs against AST symbols to prevent hallucinations, downloads checksummed GGUF models (weave slm pull), extracts ADR rules (weave slm review-rules), and maintains 0MB idle RAM.

Getting v0.1.0

Not yet on Homebrew, crates.io, npm, or PyPI — build from source until the first tagged release ships: 

git clone https://github.com/ragubaran/weave-graph.git
cd weave-graph
cargo build --release -p weave-graph-cli --features slm
cp target/release/weave /usr/local/bin/
weave-graph
