Local Pre-Push Gate

weave hooks install / uninstall

Writes a local, offline pre-push git hook that runs weave blast --base <ref> (advisory) then weave check-contracts --submodules before a push leaves the machine. Refuses to overwrite a hook it didn't write unless --force is passed; uninstall only removes a hook it installed.

Zero-Config Setup

MCP Auto-Registration

weave init creates or non-destructively merges the weave server entry into root .mcp.json. Clients that read a project-level .mcp.json (Claude Code, Cursor, and others) pick it up with no further steps; other MCP clients still need to be pointed manually at weave serve --mcp.

Smart Git & Ripgrep Ignores

Clean Version Control for Config

Configures .gitignore and .ignore with .weave/* and !.weave/config.toml. Ensures the derived graph database stays uncommitted while config.toml stays tracked in git.

RBAC Hardening

Query-Layer RBAC & Identity Sources

weave serve --mcp --require-as and [rbac] require_identity = true refuse to start an unmasked session. An identity-less --allow-drift waiver is now rejected outright once any user is granted the allow-drift role. Adds a per-user path_scope that narrows the internal role's unmask to specific paths, GitHub org/team-to-role mapping (github-auth feature), and SCIM group ingestion that accepts real Okta/Azure/Google payload shapes.

Registry Auth & Provenance

Bearer Auth & Snapshot Signing

weave-registry --auth-token requires a bearer token on every request. --provenance-key-file (feature hub-provenance) verifies a push's X-Weave-Signature header — an HMAC-SHA-256 signature over a shared operator secret — before the snapshot is committed.

12 MCP Tools

New Tools & Pre-Flight Verification

The MCP surface is now 7 core tools plus 5 feature-gated ones (2 for notes, 1 each for fts, vector, policy-lint) — up from 6. New: weave_check_freshness, weave_explore, weave_find_all, and weave_verify. A new CLI command, weave verify, is a deterministic pre-flight check for phantom symbols and stale submodule references before an agent edit lands. Note: weave_search_semantic runs on an experimental mock-embedding provider, not a trained model.

Full-Text Search

Body & Doc-Comment Indexing

weave search's BM25 FTS index (feature fts) now covers a symbol's body and doc comment, not just its name and signature.

Resource Budget

Cgroup-Aware Indexing Cap

Indexing now reads the cgroup v2/v1 memory limit (or host memory if none is set), reserves a quarter of it, and shrinks parse batches and staged writes — never grows them — to stay under budget, printing a one-line reason when it does.

Storage & Federation

Persistent Federated Queries

Composite federation graphs are persisted to .weave/federation/<partner>.db with atomic rename. weave query-federated and weave report-federated query cross-repository graphs directly instead of recomputing on every call.

Self-Hosted Tier · Updated

weave pr-review

A feature-gated (pr-review, part of custom only) risk-scored PR review artifact: reuses weave blast's own diff/traversal for a deterministic, fixed-threshold Low/Medium/High/Critical risk header — no model involved — then aggregates check-contracts-style contract drift, policy lint violations, and weave verify's phantom-symbol check into one severity-ranked findings list (blocker/warning/info, mapped to GitHub's own Checks API annotation levels). Ships with a --waive/--fail-on bypass mechanism and a documented, stable --format json contract for external LLM reviewers. New: --stack-base <ref> (or auto) scores a stacked branch's own diff separately from the cumulative diff to its merge target — nearest-ancestor auto-detection uses plain git merge-base, no vendor-specific on-disk state — and --lane <ref> (repeatable) scores additional refs independently alongside the main report.

Version 1.0.0 Initial Release Commit 7d2b8b9

Weave Graph v1.0.0 — The Deterministic Core & Graph Foundation

Initial foundation release: Pure Rust 2024 deterministic engine, integer-compacted CSR graph indexing, crash-safe atomic database staging, and native loopback MCP server.

1. Pure Rust 2024 Deterministic Graph Core

Engineered with zero runtime dependencies (no Node.js, no Python, no JVM). Deterministic point lookups run in single-digit microseconds, with no network calls in the default build.

2. Integer-Compacted CSR Matrix Traversal

Adjacency traversals leverage contiguous 32-bit CSR matrices and Roaring bitmaps. Consumes only ~12.0 bytes/node and ~4.0 bytes/edge forward — see Performance for measured RAM figures at scale.

3. Atomic Swap Reindexing & Bidirectional Edge Purge

Crash-resilient by design. Large rebuilds write safely to .weave/graph.db.rebuild and execute an atomic OS swap. Incremental updates enforce bidirectional purging of both source_id and target_id, eliminating orphaned graph pointers.

4. Native Model Context Protocol (MCP) Server

Exposes 4 core tools (weave_trace_calls, weave_impact_radius, weave_repo_map, weave_file_api) over stdio and localhost loopback. Zero external proxy or adapter required.

5. Multi-Repo & Monorepo Federation Mode

Enables multi-repo federations to be declared via weave link <repo-a> <repo-b>, resolving dependencies across workspace boundaries with virtual schemas.

6. Local SLM Linking & Intent Routing (--features slm)

Experimental. Optional on-device SLM linking (weave ask) for terminal queries with no network call. Grounds natural-language inputs against indexed AST symbols before acting on them, and downloads checksummed GGUF models via weave slm pull. Not part of the core value proposition — real-model latency/accuracy figures depend on a downloaded model and are not yet published.

Getting Started & Installation

Build Weave Graph directly from source with full optimization profile: 

# Clone and build the release binary
git clone https://github.com/ragubaran/weave-graph.git
cd weave-graph
cargo build --release -p weave-graph-cli

# Initialize graph and auto-configure AI Agent MCP (.mcp.json)
./target/release/weave init
./target/release/weave index
