Weave Graph v1.0.1 — Extended Multi-Language Support & Contract Verification

Release 1.0.1 introduces 17 additional Tree-sitter language grammars, boundary contract hashing (weave check-contracts), live MCP server auto-reload, progressive token budgeting, and PR blast radius analysis.

17 Extended Languages

29+ Supported Languages

Extends Tree-sitter parsing under --features lang-extended with 17 new languages: ArkTS (.ets), Objective-C/C++ (.m, .mm), Metal (.metal), CUDA (.cu, .cuh), Svelte (.svelte), Vue (.vue), Astro (.astro), Liquid (.liquid), Pascal/Delphi (.pas, .pp), Luau (.luau), CFML (.cfm, .cfc), COBOL (.cbl, .cob), Visual Basic .NET (.vb), Erlang (.erl, .hrl), Solidity (.sol), Terraform/OpenTofu (.tf, .tofu), and Nix (.nix).

CI Contract Gate

Boundary Contract Verification

weave check-contracts calculates deterministic SHA-256 signatures of public API surfaces. Catches cross-service breaking changes, signature drift, and missing exports in CI with zero network dependencies.

Zero Stale Queries

MCP Live Reload On External Reindex

weave serve --mcp detects external database updates via a rate-limited monotonic mtime check. Automatically reopens SQLite connections and rebuilds CSR graphs seamlessly without dropping active sessions.

92% Token Savings

3-Tier Progressive Token Budgeting

All MCP tools accept max_tokens. When output exceeds budget, tools shed detail across Level-of-Detail (LOD) tiers: module summary → file boundaries → symbol wiring cards, keeping LLMs focused and within context limits.

PR Safety Gate

Blast Radius Impact Graph

weave blast --base <git-ref> analyzes git diffs, traverses call hierarchies, and reports affected downstream callers, affected public interfaces, and risk scores formatted as PR comments.

Visual Intelligence

Obsidian Canvas Architecture Exporter

weave report --format canvas exports interactive 2D graph architectures directly into JSON Canvas (.canvas) specification with Louvain community cluster layouts.

Weave Graph v1.0.0 — The Deterministic Core & Graph Foundation

Initial foundation release: Pure Rust 2024 deterministic engine, integer-compacted CSR graph indexing, crash-safe atomic database staging, and native loopback MCP server.

1. Pure Rust 2024 Deterministic Graph Core

Engineered with zero runtime dependencies (no Node.js, no Python, no JVM). Executes 100% deterministically with sub-millisecond point lookups and zero cloud leaks.

2. Integer-Compacted CSR Matrix Traversal

Adjacency traversals leverage contiguous 32-bit CSR matrices and Roaring bitmaps. Consumes only ~12.0 bytes/node and ~4.0 bytes/edge forward (<41MB peak RSS for 500k symbols).

3. Atomic Swap Reindexing & Bidirectional Edge Purge

Crash-resilient by design. Large rebuilds write safely to .weave/graph.db.rebuild and execute an atomic OS swap. Incremental updates enforce bidirectional purging of both source_id and target_id, eliminating orphaned graph pointers.

4. Native Model Context Protocol (MCP) Server

Exposes 4 core tools (weave_trace_calls, weave_impact_radius, weave_repo_map, weave_file_api) over stdio and localhost loopback. Zero external proxy or adapter required.

5. Multi-Repo & Monorepo Federation Mode

Enables multi-repo federations to be declared via weave repo add, resolving dependencies across workspace boundaries with virtual schemas.

6. Local SLM Linking & Intent Routing (--features slm)

Optional on-device SLM linking (weave ask) for zero-cloud terminal queries. Strictly grounds natural language inputs against AST symbols to prevent hallucinations, downloads checksummed GGUF models (weave slm pull), extracts ADR rules (weave slm review-rules), and maintains 0MB idle RAM.

Getting Started & Installation

Build Weave Graph directly from source with full optimization profile: 

# Clone and build the release binary
git clone https://github.com/ragubaran/weave-graph.git
cd weave-graph
cargo build --release -p weave-graph-cli

# Initialize graph and auto-configure AI Agent MCP (.mcp.json)
./target/release/weave init
./target/release/weave index
